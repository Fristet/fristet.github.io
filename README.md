# Senior Technical Artist Portfolio

시니어 테크니컬 아티스트 포트폴리오 웹사이트입니다.

## 🎨 프로젝트 소개

이 포트폴리오는 게임 개발 및 실시간 렌더링 분야에서의 기술적 전문성을 보여주기 위해 제작되었습니다.

## 🚀 주요 기능

- **반응형 디자인**: 모바일, 태블릿, PC 모든 디바이스에서 최적화된 경험 제공
- **프로젝트 쇼케이스**: 주요 프로젝트를 카드 형식으로 전시
- **상세 페이지 모달**: 프로젝트 클릭 시 상세 정보를 모달로 표시
- **부드러운 애니메이션**: 사용자 경험을 향상시키는 자연스러운 전환 효과
- **모바일 친화적 내비게이션**: 햄버거 메뉴를 통한 모바일 네비게이션

## 📁 파일 구조

```
fristet.github.io/
├── index.html          # 메인 HTML 파일
├── styles.css          # 스타일시트
├── script.js           # JavaScript 기능
└── README.md           # 프로젝트 문서
```

## 🛠️ 사용 기술

- **HTML5**: 시맨틱 마크업
- **CSS3**: Flexbox, Grid, 애니메이션, 미디어 쿼리
- **JavaScript (ES6+)**: 동적 콘텐츠 렌더링, 이벤트 핸들링

## 📝 커스터마이징 가이드

### 1. 개인 정보 수정

`index.html` 파일에서 다음 섹션을 수정하세요:

- **히어로 섹션**: 타이틀과 소개 문구
- **About 섹션**: 전문 분야 및 기술 스택
- **Contact 섹션**: 이메일, GitHub, LinkedIn 링크

### 2. 프로젝트 추가/수정

`script.js` 파일의 `projects` 배열에서 프로젝트를 추가하거나 수정할 수 있습니다:

```javascript
{
    id: 7,
    title: "새 프로젝트 제목",
    category: "카테고리",
    description: "간단한 설명",
    tags: ["태그1", "태그2"],
    image: "images/project.jpg", // 또는 null
    details: {
        overview: "상세 개요",
        responsibilities: ["업무1", "업무2"],
        technologies: "사용 기술",
        results: "성과"
    }
}
```

### 3. 색상 테마 변경

`styles.css` 파일의 `:root` 섹션에서 CSS 변수를 수정하세요:

```css
:root {
    --primary-color: #2563eb;    /* 메인 색상 */
    --secondary-color: #1e40af;  /* 보조 색상 */
    --accent-color: #60a5fa;     /* 강조 색상 */
    /* ... */
}
```

### 4. 프로젝트 이미지 추가

1. 프로젝트 루트에 `images` 폴더 생성
2. 이미지 파일을 해당 폴더에 추가
3. `script.js`의 프로젝트 데이터에서 `image: "images/your-image.jpg"` 형식으로 경로 지정

## 🌐 GitHub Pages 배포

1. GitHub 저장소 설정에서 Pages 활성화
2. 소스를 `main` 브랜치의 루트로 설정
3. 몇 분 후 `https://fristet.github.io`에서 사이트 확인 가능
